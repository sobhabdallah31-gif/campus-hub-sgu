# Campus Hub

بوابة جامعية عربية بخادم Kotlin وKtor. الواجهة تعرض لوحات مستقلة للطالب وعضو هيئة التدريس والإدارة، مع جدول ومقررات وطلبات ومواعيد توضيحية.

## التشغيل

- ثبّت Java 17 أو أحدث.
- من هذا المجلد شغّل `gradlew.bat run` (أو افتح المشروع في IntelliJ IDEA واترك Gradle يحمّل الاعتماديات).
- افتح [http://localhost:8080](http://localhost:8080).

## نشر برابط دائم

المشروع جاهز للنشر على Render باستخدام `Dockerfile` و`render.yaml`. اربط مستودع GitHub خاصًا بالمشروع في Render واختر خطة Free. سيظهر عنوان دائم من نوع `*.onrender.com`. الخدمة المجانية قد تنام بعد 15 دقيقة من عدم الاستخدام، وقد يستغرق أول فتح بعدها قرابة دقيقة.

لكل دور صفحة مستقلة: `/student` للطالب، و`/instructor` لعضو هيئة التدريس، و`/admin` للإدارة. في المعاينة المحلية افتح `index.html` أو `instructor.html` أو `admin.html` مباشرة. يتولى Ktor تقديم الصفحات المناسبة حسب المسار.

كل الأسماء والأرقام المعروضة تجريبية. تسجيل الدخول وقاعدة البيانات وإرسال الطلبات تحتاج ربطًا بخدمات الجامعة الفعلية.
